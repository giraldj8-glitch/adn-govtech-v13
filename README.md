# ADN GovTech v13 · preguntas breves

Prototipo para validación. Nueva versión independiente de v12.

- Completo: 20 preguntas ADN (SER 3, HACER 8, TENER 9), más contexto y opinión.
- Summit propuesto: 15 preguntas ADN, con `?recorrido=summit`.
- Vistas: tarjetas, lista breve y comparación de dos preguntas. `?vista=bloques` abre la comparación.
- Quiosco: `?modo=quiosco`.

Se conservan las asociaciones de las 19 preguntas retenidas. Se retira P0.4 y se añade P17: su asociación a arquetipo es experimental y no puntúa en el radar. La clasificación puede cambiar frente a v12. Los puntajes heredados requieren validación.

La reducción de palabras no demuestra una reducción de tiempo; está pendiente probar comprensión y duración con empresas.

Las respuestas permanecen en el navegador y pueden descargarse. Este repositorio solo contiene el prototipo publicado, sin respuestas de usuarios ni documentos de reuniones.
